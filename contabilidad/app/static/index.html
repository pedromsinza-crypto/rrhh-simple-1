Solicitar acceso demo de 5 días

El correo se verifica con un código. El administrador revisa manualmente cédula, RIF, dirección y profesión; los 5 días comienzan al aprobar la solicitud.

Aviso de privacidad de la solicitud demo

El administrador del sistema tratará tu nombre, correo, contraseña cifrada, cédula, RIF, dirección y profesión para verificar el correo, revisar manualmente la solicitud y administrar el acceso demo. La contraseña se almacena como hash y el código de correo solo como resumen criptográfico.

El correo de verificación se entrega mediante el proveedor SMTP que configure el operador. Los archivos de facturas solo se envían a Azure si una persona autorizada solicita explícitamente el OCR. No se transmiten datos al SENIAT ni a bancos desde este formulario.

Las solicitudes de acceso y la información personal de revisión se conservarán por un máximo operativo de 90 días desde su creación y después se eliminarán mediante la tarea de retención configurada. Si se aprueba el acceso, los datos de perfil necesarios para la cuenta permanecen mientras exista la cuenta o una obligación legal de conservación. Este aviso es un borrador operativo: antes de ofrecer el formulario públicamente, el operador debe completar su identidad y contacto legal, confirmar la base jurídica y validar los plazos con asesoría competente.
